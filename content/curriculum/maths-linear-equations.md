# Linear Equations in One Variable

A linear equation in one variable is an equation that can be written in the form ax + b = 0, where a is not zero. Its highest power of the variable is 1, and it has exactly one solution.

## The balance method

An equation is like a balance scale: the left side equals the right side. Whatever operation you do to one side, you must do to the other to keep it balanced.

To solve, use inverse operations to isolate the variable:

- Undo addition with subtraction, and subtraction with addition.
- Undo multiplication with division, and division with multiplication.

## Worked example

Solve 2x + 3 = 11.

1. Subtract 3 from both sides: 2x = 8.
2. Divide both sides by 2: x = 4.
3. Check by substituting back: 2(4) + 3 = 11. Correct.

## Equations with variables on both sides

Solve 5x - 2 = 3x + 6.

1. Subtract 3x from both sides: 2x - 2 = 6.
2. Add 2 to both sides: 2x = 8.
3. Divide by 2: x = 4.

## Word problems

Translate the words into an equation, solve, then interpret the answer. Always define the variable first, for example "let x be the number of pens".

## Common mistakes

- Forgetting to apply an operation to every term on both sides.
- Sign errors when moving terms across the equals sign.
- Not checking the answer by substitution.
